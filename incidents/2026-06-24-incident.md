# Incident: Windows 11 Setup

Date: June 24th, 2026

Severity: Low

## Summary

Setup of Windows 11 VM via libvirt with KVM + QEMU stack.

## Timeline

Untracked

## Impact

Nothing else beyond the scope of this exact virtual machine was affected.

## Root Cause

Faulty SCSI/SATA routing; pointed to VirtIO ISO file. Directed both to Windows 11 ISO

Incorrect ISO ejection/insertion orders with Windows 11 and VirtIO ISOs.

## Resolution

Created a functional Windows 11 virtual machine for breaking and fixing.

## Prevention

Make sure SCSI and SATA route to the actual ISO file of the system, and follow this insertion/ejection order for the next VM:

1. Eject base OS ISO and replace with VirtIO during drive selection process
2. Before pressing install, eject VirtIO and insert the base OS ISO again
3. On first reboot, eject the base ISO
